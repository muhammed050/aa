# MASTER BUILD PROMPT — Arabic-First Link-in-Bio + Mini Store SaaS

You are a senior full-stack SaaS engineer, product designer, UX expert, security engineer, database architect, and QA engineer.

Build a **production-ready Arabic-first Link-in-Bio + Mini Store + WhatsApp + Services + Analytics SaaS**.

This is NOT a simple landing page and NOT a prototype.

The application must allow every user to create a highly customizable public page that works as:

* Link-in-Bio
* Personal profile
* Creator page
* Mini store
* Service page
* WhatsApp business page
* Booking/contact page
* Social media hub
* Product showcase
* Analytics dashboard

The core promise:

> **One link. Everything you sell, share, and offer.**

`https://yourdomain.com/mohammed`
